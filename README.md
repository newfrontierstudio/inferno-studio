# inferno Studio

録画した動画を見ながら、CMなど不要な範囲を手動でカットするWindows用アプリです。Zoo／Studioがなくても単体で起動できます。

[最新版をダウンロード](https://github.com/newfrontierstudio/inferno-studio/releases/latest)

**0.8.2：サムネイル表示中の画像解放処理を修正し、右ドラッグを最大×1024に拡張しました。**

## 主な機能

- IN／OUTで範囲を選び、不要な部分を削除。元動画は残して別ファイルへ書き出します。
- アプリ内で再生。Spaceキー、または映像クリックで再生／停止します。
- 映像・タイムライン上の右ドラッグで順方向／逆方向へ移動。速度は連続的に変わり、最大×1024です。
- 素材一覧のホバースクラブ。行の左10％で先頭、右90％で末尾に届きます。メイン映像や編集位置とは連動しません。
- 縦型L/Rピークメーター、ヘッドルーム表示、共通の試聴音量フェーダー。試聴音量・ミュートは書き出しに影響しません。
- MP4（AV1）へ書き出し。対応GPUによるエンコードとCPUエンコードを選べ、ビットレートは小数でも指定できます。

サムネイル生成は表示サイズに合わせ、同じ位置のプレビューを再利用して処理負荷を抑えています。無音時のメーター再描画も削減しています。

## インストール

Windows 10/11（64ビット）向け。インストーラーは約2.23MBです。

.NET 8 Desktop Runtimeと動画部品が未導入の場合は、インストーラーが取得して準備します。初回はインターネット接続が必要で、.NETの導入には管理者の許可が必要です。導入済みの部品は再利用します。

更新前にInfernoをすべて閉じてください。既定の場所にZoo／Studioがインストールされている場合は、その同梱Infernoも更新します。Zoo／Studio本体の再インストールは不要です。

## 書き出しについて

元動画は上書きしません。音声はAACへ変換します。放送字幕・データ放送・副音声は出力対象外です。
