# inferno Studio

録画した動画を見ながら、CMなど不要な範囲を手動でカットするWindows用アプリです。Zoo／Studioがなくても単体で使えます。

[最新版をダウンロード](https://github.com/newfrontierstudio/inferno-studio/releases/latest)

## 0.11.5の更新

- 映像上のホイールで表示サイズを変更。倍率を表示し、ダブルクリックで100％へ戻せます。
- メーター／スライダー上のホイールで試聴音量を調整。基本1％刻みで、素早く回し続けると緩やかに加速します。
- 倍率・試聴音量・ミュートを保存し、次回起動時に復元します。
- 素材の追加・削除を自動反映。タイムライン上のホイールで拡大・縮小できます。
- 編集ポイントをシアンで区別し、起動アイコンも修正しました。

## 主な機能

IN／OUTで範囲を選び、不要な部分を削除します。元動画は残して別ファイルへ書き出します。画面クリック／Spaceで再生・停止し、コマ送りや素材一覧のホバースクラブで位置を探せます。右ホールド操作は削除しました。

縦型L/Rピークメーターとヘッドルーム表示に対応。表示倍率と試聴音量は書き出しに影響しません。

MP4（AV1・H.264・HEVC）とMOV（ProRes）に対応。利用できるエンコーダーは環境によって異なります。放送字幕・データ放送・副音声は出力対象外です。

## インストール

Windows 10／11・64bit向け。必要な部品は初回にダウンロードします。導入済みの部品は再利用します。

更新前にInfernoを終了してください。通常の場所にインストールされているZoo／StudioのInfernoも更新します。Zoo／Studio本体の再インストールは不要です。

このリポジトリではインストーラーと利用案内を配布します。アプリ本体のソースは含めていません。部品のライセンス表記は同梱の案内をご確認ください。
