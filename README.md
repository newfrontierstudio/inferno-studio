# inferno Studio

録画した動画を見ながら、CMなど不要な範囲を手動でカットするWindows用アプリです。Zoo／Studioがなくても単体で使えます。  
A Windows application for cutting recorded video by hand — mark the ranges you do not need, and export what remains. It works on its own, without Zoo / Studio.

[最新版をダウンロード / Download the latest version](https://github.com/newfrontierstudio/inferno-studio/releases/latest)

inferno Studio is a Windows application for cutting recorded video by hand. Watch a recording, mark the ranges you do not need — commercials and the like — and export what remains as a new file. The original is never touched. It works on its own; no other application from the suite is required.

Editing is deliberately simple. Set IN and OUT points to choose a range, delete it, and export. Click the picture or press Space to play and stop; step frame by frame, or hover over the library thumbnails and scrub to find a position. Edit points are marked in cyan, so the cuts are easy to see.

Sound is treated with the same care as the picture. Vertical L/R peak meters show headroom while you listen. The wheel over the meter or slider adjusts the monitoring volume in 1% steps, accelerating gently when you keep turning. Display zoom, monitoring volume and mute are remembered for the next launch — and none of them affect the exported file.

The wheel over the picture zooms the display, with the magnification shown; double-click returns to 100%. The wheel over the timeline zooms the timeline itself. Files added to or removed from the folder appear in the library automatically.

- Formats: MP4 (AV1, H.264, HEVC) and MOV (ProRes). Available encoders depend on the environment. Broadcast captions, data broadcasting and sub-audio are not exported.
- Windows 10 / 11, 64-bit. The components it needs are downloaded on first install, and components already on the PC are reused.
- Installing inferno Studio also updates the Inferno bundled with Zoo / Studio installations in their usual locations. Zoo / Studio themselves do not need to be reinstalled.

inferno Studio は、録画した動画を見ながら手動でカットする Windows 用アプリです。CM など不要な範囲を選んで取り除き、残りを別ファイルへ書き出します。元動画には手を付けません。単体で使え、スイートの他のアプリは不要です。

編集は意図的にシンプルです。IN / OUT で範囲を選び、削除して、書き出す。画面クリックや Space で再生・停止し、コマ送りや、素材一覧のホバースクラブで位置を探せます。編集ポイントはシアンで表示され、カット位置が一目で分かります。

音も映像と同じだけ丁寧に扱います。縦型 L/R ピークメーターでヘッドルームを見ながら試聴できます。メーターやスライダー上のホイールで試聴音量を 1% 刻みで調整でき、回し続けると緩やかに加速します。表示倍率・試聴音量・ミュートは次回起動時に復元され、書き出しには影響しません。

映像上のホイールで表示を拡大・縮小し、倍率が表示されます。ダブルクリックで 100% に戻ります。タイムライン上のホイールではタイムライン自体を拡大・縮小できます。フォルダへの素材の追加・削除は一覧に自動で反映されます。

- 対応形式: MP4 (AV1・H.264・HEVC) と MOV (ProRes)。利用できるエンコーダーは環境によって異なります。放送字幕・データ放送・副音声は出力対象外です
- Windows 10 / 11、64bit。必要な部品は初回にダウンロードし、導入済みの部品は再利用します
- inferno Studio のインストールで、通常の場所にインストールされている Zoo / Studio の Inferno も更新されます。Zoo / Studio 本体の再インストールは不要です
